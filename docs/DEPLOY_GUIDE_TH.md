# คู่มือตรวจสอบหลังจัดโครงสร้าง

## เช็กการทำงานก่อนนำขึ้นจริง

- [ ] `npm install` และ `npm run dev` เปิดหน้าเว็บได้
- [ ] หน้าสรุปและหน้าขายสินค้าแสดงผลครบ
- [ ] ไอคอนเมนูหลัก 10 รูปไม่หาย
- [ ] หน้า POS เลือกสินค้า/แก้ตะกร้าได้ (ทดลองกับข้อมูล DEV เท่านั้น)
- [ ] Supabase เชื่อมต่อได้เมื่อเปิดใน DEV
- [ ] `npm run build` สร้าง `dist/` ได้
- [ ] ทดสอบจริงด้วยแท็บเล็ต Android/iPad แนวตั้งและแนวนอน
- [ ] HTTPS ใช้งานได้และ PWA ติดตั้งได้
- [ ] ตรวจว่าไม่พบ 404 ที่ `/js/app.js`, `/css/app.css`, `/sw.js`, `/manifest.json`
- [ ] บิลออฟไลน์ทดลองซิงค์ใน DEV และตรวจสอบว่าไม่เกิดบิลซ้ำ

## จุดแก้ไขไฟล์หลัก

- หน้า HTML: `index.html`
- โค้ดการทำงาน: `js/app.js`
- CSS ทั้งหมด: `css/app.css` และ `css/pages/`
- ปรับจอแท็บเล็ต: `css/tablet-enhancements.css`
- ติดตั้งเป็นแอป: `js/install-app.js`
- PWA แคช: `sw.js` และ `manifest.json`

> เนื่องจากใช้ Service Worker เมื่อปล่อยเวอร์ชันใหม่แล้ว ควรทดสอบการอัปเดตแอปที่เคยติดตั้งบนอุปกรณ์เดิมด้วย
